# Demo URL Configuration

Edit `src/data/projects.ts` and set the `demoUrl` field for each project after deployment:

```ts
id: 'fireline-cop',
demoUrl: 'https://...'

id: 'aerolearn-ai',
demoUrl: 'https://...'

id: 'aerofleet',
demoUrl: 'https://...'
```

Until a URL is supplied, the portfolio displays “Demo link coming soon” instead of inventing a live link.
